Bleichenbacher's padding oracle attack is an attack that originally targeted SSLv3.

It makes use of three properties:
  - The padding scheme of PKCS \#1 v1.5
  - the homomorphism of RSA
  - the padding oracle and the information it leaks

## Padding in PKCS \#1 v1.5

Since SSLv3 encrypts all messages $M$ using RSA, the messages can be no longer than the
Modulus $N$[^1]. To extend shorter messages to this length SSLv3 used the padding as defined
in PKCS \#1 v1.5. An SSLv3 block starts with the padding.

The padding starts with `0x002` then follows $\text{len}(M) -3$ random non-0 bytes and finally
another 0 byte.
